# radial_burst

Nacen cerca del centro y salen disparadas en todas direcciones. Con `react_to: bass` o `beat`, cada golpe
las acelera y queda como una explosión.

```yaml
particles:
  enabled: true
  type: "radial_burst"
  count: 120
  speed: 1.5
  audio_boost: 3.0
  color: "#ffffff"
  glow: true
```
Opciones: ver [capas](README.md#opciones-de-cada-capa).
