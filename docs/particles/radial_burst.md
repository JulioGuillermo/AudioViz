# radial_burst

They spawn near the center and shoot out in all directions. With `react_to: bass` or `beat`, each beat
speeds them up, so it looks like an explosion.

```yaml
particles:
  enabled: true
  type: "radial_burst"
  count: 120
  speed: 1.5
  audio_boost: 3.0
  color: "#ffffff"
  glow: true
```
Options: see [layers](README.md#per-layer-options).
